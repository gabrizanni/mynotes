# Codex lesson writing

New Codex notes requests use one structured writing pass. Complete source text
travels on stdin; contact sheets travel as native image attachments. The strict
transport schema uses short registered page aliases and leaves the duplicated
coverage register empty for local derivation. Model and reasoning settings are
preserved. No automatic reviewer or second full writing pass is added.

Notebook cells and document paragraphs can share the S evidence namespace with
PDF pages. Only the explicit ownership registry identifies assignable pages.
Their original content and narrative citations remain available in full.
Supplement placement follows substantive narrative, including shared-source
blocks, rather than requiring PDF page order. Recall-only citations cannot
satisfy a missing supplementary explanation.

Preview attachments certify only previews. Included source figures require a
successful full-image access event. Raw JSONL events, stdin identity, final-file
identity and source-access records are retained in the private provider attempt.
A successful retained response is reconstructed from its terminal transport
before each local projection; resume never rewrites that original response.

`CODEX_LAUNCH_DENIED` identifies local Codex initialization/permission failure.
The coordinator must use its supported command-permission mechanism for the
exact MyNotes command. The child sandbox cannot expand its parent's permissions.
Do not switch to unrestricted execution or repeat generation to hide a denial.

A source-backed content gap, changed source, changed prior publication, or
conflicting settled slide ownership still stops delivery with retained content.
Newly published earlier lessons can change the ownership/continuity of a later
independently generated attempt; that requires explicit reconciliation, not an
automatic full rewrite. Rendering errors are local Word failures and must not
trigger another model call.

Agy's adapter, writing protocol and default projection behavior are unchanged.
The additional projection restrictions are selected only for Codex protocol 3.
The shared equation renderer additionally accepts named operators and stacked
sum conditions as native editable Word mathematics.
